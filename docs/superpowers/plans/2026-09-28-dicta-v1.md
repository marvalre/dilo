# Dicta v1 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Hold a key, speak, and have locally-transcribed text pasted at the cursor, with a cute mascot next to the mouse, plus a tray panel with History / Stats / Settings.

**Architecture:** Tauri v2 app. Rust core (`src-tauri/src/*`) split into single-purpose modules (hotkey, recorder, engine, paste, store, stats, models, mascot, coordinator, settings, tray). Two webviews from one Vite+React+TS bundle: `mascot.html` (transparent click-through window following the cursor) and `index.html` (panel).

**Tech Stack:** Rust 1.98, Tauri 2, React 18 + TypeScript + Vite (bun), `transcribe-rs 0.3` (feature `onnx`), `handy-keys 0.3`, `cpal`, `rubato`, `enigo 0.6`, `arboard`, `rusqlite` (bundled), `reqwest` (blocking), `whatlang`.

**Spec:** `docs/superpowers/specs/2026-09-28-dicta-design.md`

## Global Constraints

- App id `com.dicta.app`, product name `Dicta` (provisional name).
- macOS first (dev machine: Apple M5, macOS 26.6). Code must still compile on Windows/Linux (use `cfg` for platform bits).
- No Dock icon on macOS (`ActivationPolicy::Accessory`).
- Default hotkey: `"Fn"` on macOS, `"CtrlRight"` on others (handy-keys string syntax).
- Default model: Parakeet TDT 0.6B v3 int8 from `https://huggingface.co/istupakov/parakeet-tdt-0.6b-v3-onnx/resolve/main/<file>`; files: `encoder-model.int8.onnx`, `decoder_joint-model.int8.onnx`, `nemo128.onnx`, `vocab.txt`. Stored in `<app_data>/models/parakeet-tdt-0.6b-v3-int8/`.
- Audio fed to engine: mono f32 at 16 000 Hz.
- Minimum dictation: 300 ms and RMS peak > 0.01, else cancel.
- Model idle-unload default: 10 minutes.
- Mascot: 44 px body in a 72×72 window, offset (+28,+28) from cursor, 60 Hz follow.
- DB table `dictations` exactly as in spec §6.
- Credits: README must credit Handy (MIT) and name the crates used.

### Task 2: `stats` — pure functions (TDD)

**Interfaces — Produces:**
```rust
pub fn count_words(text: &str) -> u32;
pub struct DayWords { pub day: chrono::NaiveDate, pub words: u32 }
pub struct Entry { pub created_at_ms: i64, pub duration_ms: i64, pub words: u32, pub language: Option<String> }
#[derive(Serialize)] pub struct Stats {
  pub total_words: u64, pub words_today: u64, pub total_dictations: u64,
  pub avg_words_per_day: f64, pub avg_words_per_dictation: f64, pub avg_wpm: f64,
  pub current_streak: u32, pub time_saved_min: f64,
  pub last_30_days: Vec<(String /*YYYY-MM-DD*/, u64)>, pub languages: Vec<(String, u64)>,
}
pub fn compute(entries: &[Entry], now_ms: i64, tz: &impl chrono::TimeZone) -> Stats;
```
Rules: word = whitespace token containing ≥1 alphanumeric char. avg_words_per_day = total_words / number of distinct active days. avg_wpm = total_words / (total_duration_ms / 60000). streak = consecutive days ending today (or yesterday if nothing today) with ≥1 dictation. time_saved_min = max(0, total_words/40 − total_duration_min). Errors (words=0 rows) excluded upstream.

- [ ] Write tests: `count_words("Hola, ¿cómo estás?") == 3`, `count_words("  ... — 🙂 ") == 0`, `count_words("e-mail test123") == 2`; streak across 3 consecutive days = 3, gap resets; today-empty-yesterday-active keeps streak; midnight bucketing with fixed offset tz; wpm with 120 words in 60 000 ms = 120.
- [ ] `cargo test stats` fails → implement → passes. Commit.

### Task 3: `store` — SQLite (TDD)

```rust
pub struct NewDictation { pub created_at: i64, pub duration_ms: i64, pub text: String, pub language: Option<String>, pub app_name: Option<String>, pub error: Option<String> }
impl Store {
  pub fn open(path: &Path) -> Result<Self>; pub fn open_in_memory() -> Result<Self>;

  pub fn delete(&self, id: i64) -> Result<()>;
  pub fn stats(&self, now_ms: i64) -> Result<stats::Stats>; // local tz, excludes error rows
}
```
- [ ] Tests: insert→list returns it with word_count; search filters; delete removes; stats totals match. Implement; pass; commit.

### Task 7: `recorder`

**Produces:** `pub struct Recorder` with `start(on_level: impl Fn(f32)+Send+'static) -> Result<()>`, `stop() -> Result<Recording>` where `Recording { samples: Vec<f32> /*16k mono*/, duration_ms: i64, peak_rms: f32 }`. Uses cpal default input; downmix to mono; resample with `rubato` (SincFixedIn or FftFixedIn) to 16k at stop; level = RMS×12 clamped 0..1 per callback, throttled to ~30 Hz. Stream lives on a dedicated thread (cpal Stream is !Send on macOS).
- [ ] Unit test `downmix` and `resample` helpers (sine 48k 1 s → ~16000 samples). Commit.

### Task 8: `paste`

**Produces:** `pub fn paste_text(text: &str) -> Result<()>`: save clipboard text (arboard), set text, sleep 40 ms, enigo key: macOS `Meta+v`, else `Control+v`, sleep 300 ms, restore previous text (if any). Trailing space appended to text so consecutive dictations don't glue. Manual verification only. Commit.

### Task 11: `coordinator` + tray + commands (wire it all)

State machine: `Idle → (pressed) Recording → (released) Transcribing → Pasting → Idle`. Pressed while not Idle ignored. On release: cancel if too short/silent (swallow). Else thinking → engine on worker thread → paste → store.insert → mascot done → swallow. Errors → sad + store row with error. If model not ready → open panel on Settings (model section) and show confused. Frontmost app name (macOS `NSWorkspace.frontmostApplication.localizedName` via `objc2-app-kit`, else None) captured at press time.
Tray menu: "Abrir Dicta", Language submenu (Auto, es, en, fr, de, pt, it), "Salir". Left-click opens panel.
Commands: `get_history(query, offset)`, `delete_dictation(id)`, `get_stats()`, `get_settings()`, `save_settings(s)`, `model_status() -> {ready, downloading, progress}`, `download_model()`, `copy_text(text)`, `permissions() -> {accessibility, microphone}`, `open_accessibility_settings()`.
Events: `model://progress {done,total}`, `history://changed`.
- [ ] `cargo build` ok, manual run: hold Fn in TextEdit → text pasted. Commit.
